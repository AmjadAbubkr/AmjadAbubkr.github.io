## Facebook accessibility limitation

Direct requests to the supplied profile and Code For Chad Facebook URL returned HTTP 200 pages with Facebook titles, but the usable post/page content was unavailable in the no-login browsing context. The web reader also reported the supplied profile and page URLs as throttled. The user then supplied the text of two Code For Chad posts; their specific post permalinks were not included.

## Identity and claim risks

- The supplied profile uses `Amjad Abubkr`, while the site’s intended public name is `Amdjad Aboubakar`. A portfolio should not silently treat them as the same person without corroboration.
- A like, tag, membership, event attendance, or photograph would not by itself substantiate a meaningful collaboration or a particular role. Use a first-party post that names the person and contribution, or obtain a short written confirmation from the organisation.
- Before publishing, prefer a dated organisation post/page stating the exact role, project, and outcome; otherwise phrase any verified personal material narrowly and link it directly.
